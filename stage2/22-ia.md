# 第 22 章 输入装配器（IA）

> 本章把初级的"固定 `RenderVertex` 非索引 IA"替换为完整输入装配：索引缓冲、`VertexInputLayout` 动态装配、Primitive Restart、step rate 实例化、以及 `baseVertex/baseInstance/InstanceID`。IA 只消费 `VertexInputLayout`，不感知 API 顶点格式（`architecture-design.md` §3.7）。
> 与本章相关的设计说明：`../architecture-design.md` §3.7（层间数据契约：`VertexInputLayout`）；`../design/command-mmio.md` §2（`DRAW.indexed` 标志）；ADR-017（`IEngine::Execute` 末参 `IShaderArray*`、不拆批）。
> 落地模块：`hw_sim/frontend/ia`、`apps/scene_s5_model`。

---

## 1. 目标与非目标

### 1.1 目标

1. 索引装配：`indexFormat ∈ {u16, u32}`；索引越界定位于资源 VA。
2. `VertexInputLayout`：多属性流（`bufferBase/bufferStride/offsetInVertex/format/stepRate`）动态装配；非索引路径等价保留。
3. Primitive Restart：索引值 `0xFFFF`（u16）/`0xFFFFFFFF`（u32）触发重启，复位条带/扇状拓扑状态（与索引缓冲、实例化交互）。
4. 实例化：`baseVertex/baseInstance/InstanceID`；step rate 非 0 时属性每实例变化。
5. 拓扑族：`TriangleList/TriangleStrip/TriangleFan/LineList/LineStrip/PointList`（第 6 章只支持 0=TriangleList）；`PrimitiveTopology` 为独立枚举，与 `tessDomain`（第 23 章）、GS mode（第 28 章）分立并登记映射（Q-63）。
6. 输出到 VS：装配后的顶点按布局填入 `v[0..15]`（ABI 输入属性区），`GET_VERTEX_ID/GET_INSTANCE_ID` 正确。

### 1.2 非目标

- 不做 Tess/GS 输入扩展的 patch 拓扑（第 28 章）。
- 不做 strip cut 的宽索引（restart 值固定两种）。
- 不做无缓冲的内建几何生成（GS 在第 28 章）。
- 不做 vertex pulling 之外的提取优化；全部经 `IMemorySubsystem::Read` 取属性。

## 2. 单元框图

```
 DRAW.indexed / 非索引 ──► IA
   ┌───────────────────────────────────────────────┐
   │ DrawState{firstVertex, vertexCount (或 indexNA)}│
   │ BindedIndexBuf{va, format} + restart 值          │
   │ VertexInputLayout (属性流)                      │
   │   ↓ 逐顶点                                        │
   │ 装配 → v[0..15] → 送 VS（IShaderArray）          │
   │ Topology: assemble → primitives（条带/扇状拆）    │
   └───────────────────────────────────────────────┘
```

- IA 输出顶点的 `vertexId`、`instanceId` 内建同步给 VS。
- 装配在 VS 之前完成（生成顶点列表或逐顶点 on-demand 均可，确定性优先逐顶点 on-demand 常量流）。

## 3. 输入输出契约

### 3.1 `VertexInputLayout`（`architecture-design.md` §3.7 冻结）

```cpp
struct VertexInputLayout {
    struct Attrib {
        GpuVAddr bufferBase;
        u32      bufferStride;
        u32      offsetInVertex;
        u32      format;         // 格式枚举（VtxFormat）
        u32      stepRate;       // 0=per-vertex, 非0=per-instance
    };
    std::vector<Attrib> attribs;
    u32 indexFormat;   // U16 / U32
    u32 baseVertex;
    u32 baseInstance;
};
// 取第 n 个顶点的属性 i：
//   addr = bufferBase + (perInstance ? instanceIdx : n) / max(1, stepRate) * stride + offsetInVertex
```

- 初级的 `RenderVertex` 可视为一条固定布局特例（4 属性 stream 单缓冲，`stepRate=0`），第 6 章基线不破。
- `format` 支持：`R32G32B32A32_FLOAT`、`R32G32_FLOAT`、`R32_FLOAT`、`R8G8B8A8_UNORM` 等常用集。

### 3.2 DRAW.indexed 扩展

- `DRAW` 包 `flags.bit0` 已冻结为 `indexed`（第 6 章初级实现返回 `NotSupported`）；本章实现 `flags.bit0=1` 的索引路径：载荷携带索引缓冲 VA/索引格式/索引数量（扩展载荷字段，见 §3.3）。

### 3.3 IA 状态包（DRAW 延展）

```
DRAW.indexed:  {firstVertex, vertexCount, indexBufVa, indexFormat, restartEnable}
             + 绑定 IndexBuf（SET_STATE_BASE 无关，直接载荷）
DRAW.nonindexed: {firstVertex, vertexCount}
（baseVertex/baseInstance 来自 VertexInputLayout 或 DRAW.extend；本期放 DRAW 载荷扩展字段）
```

## 4. 内部数据流

### 4.1 索引装配确定性序

```
DRAW.indexed:
  for i in [0, vertexCount):
    idx = ReadIndex(indexBufVa + i*idxSize)
    if restartEnable && idx == restartVal: 拓扑复位（当前图元截断）
    else:
      vglobal = baseVertex + idx   // 顶点全局号
      instance = baseInstance + curInstance
      装配该顶点 → (vglobal, instance, idx) → 送 VS
  topology 尾端未完成图元丢弃
DRAW.nonindexed:
  for v in [0, vertexCount): 装配 (baseVertex+v, instance) → 送 VS
```

- 索引按顺序消费；`vertexCount` 以索引计。
- `ReadIndex` 走 `IMemorySubsystem`，越界 → `NotMapped`（带索引缓冲 VA）。

### 4.2 装配属性

```
attr_i for vertex n:
  perVertex: addr = bufferBase + n*stride + offset
  perInstance: addr = bufferBase + (instanceIdx / max(1, stepRate))*stride + offset
  解码 format → float4（UI/UNORM 转换）→ v[slot]
```

- slot 映射：`attribs` 数组顺序 → ABI 输入区 `v[0..15]` 顺序（数量 ≤ 16 属性）。

### 4.3 拓扑拆分

- TriangleList：每 3 顶点 1 图元。
- TriangleStrip：图元使用最后 3 顶点；奇数序号翻转缠绕序。
- TriangleFan：第 1 顶点为扇顶，与后续相邻顶点成图元。
- LineList/LineStrip/PointList 对应。
- Restart 复位条带/扇状。

## 7. 场景与判据（A22）

**绑定场景：S5 `scene_s5_model`（索引网格；实例化 + step rate + 索引 + 条带 + restart 以 S5 参数子 case 表达；S6 细分场景属第 24/28 章）。**

| 项 | 内容 |
|---|---|
| 输入 | S5：2×2 实例方块（每实例不同色/平移），stepRate=2 实例化属性；S5 参数子 case：索引三角形（含越界负例）、strip + restart、`baseVertex/baseInstance` 组合 |
| 产物 | 装配后的顶点/内建、图元列表、RT |
| 主判据 | S5 出图 = ref_model（实例位置/颜色逐像素探针零容差） |
| 本章专有判据 | ① 索引与非索引顶点流一致（同几何两路径 RT 相同）；② Primitive Restart / step rate 正确；③ `baseVertex/baseInstance/InstanceID` 正确；④ 拓扑族 List/Strip/Fan/Line/Point 的图元列表与参考一致（含 restart 拆图元）；⑤ 内建 ID 只读 SGPR/专用寄存器（不经属性区） |
| 回归项 | A1~A21 全绿；E2/E4（非索引基线）不退化 |
| 后续补齐 | patch 拓扑 → 第 28 章 Tess；UAV pull 优化范围外 |

## 8. 横向关注点

| 关注点 | 本章回答 |
|---|---|
| 确定性 | 索引消费序固定、图元生成序固定、实例序固定 |
| 时间无关 | 无时间输入 |
| 可观测 | `vertexCount/primitiveCount` 统计、装配轨迹、`--trace=ia` |
| 契约影响 | `VertexInputLayout` 层间契约冻结；`DRAW.indexed` 载荷扩展登记 |
| 简化登记 | 固定 `RenderVertex` /非索引 → 动态布局 + 索引 + 实例化 |
| 计算兼容 | IA 是图形专用阶段（明确允许）；共用 `IMemorySubsystem` 不特化 |
| 配置与回退 | `index_format` 为 `DrawState::indexFormat` 载荷字段（非全局配置键）；restart 由 DRAW 载荷 `restartEnable` 控制，默认关 |
| 调试钩子 | `--trace=ia`：每顶点一行 `{idx, globalVert, instance, attr0..}` |
| trace 契约 | 不进入判据 |
| 契约变更 | `VertexInputLayout`/DRAW.indexed/拓扑/restart 为冻结项；变更走 ADR 回归 S5 |
| 校验归属 | L1（结构/索引）+ L2（实例化/restart 输出与 ref_model） |
| 双策略 | IA 装配与执行策略无关（切片粒度由 23 章容量决定） |
| 阶段衔接 | 为 23（VGT/SPI 分派）提供顶点流；内建为 24（裁剪）提供顶点索引 |

## 10. 待定项

- `DRAW.indexed` 载荷扩展的字段顺序（索引缓冲 VA 紧跟非索引字段尾部）待 `command-mmio.md` 登记确认，避免与其他第 20~28 章扩展冲突。
