# 执行与并行模型 — 独立模块设计

> 项目目标、范围、阶段与交付以[任务规划](../CPU模拟GPU教学项目_任务规划与实施规格.md)为主干；roadmap展开章级任务，architecture-design定义模块树与层间契约。本文负责本模块的内部技术设计。

> 定位：定义 SIMT 执行与调度、波调度、双执行策略（策略 A 确定性串行 / 策略 B 硬件对齐并行）、SE/CU 阵列分区与 occupancy 资源上限，以及"时间无关 + 确定性"的全局规则。
> 落地章：第 4 章 SIMT 单波（初级）、第 15 章分歧与波调度、第 31 章 SE + CU 阵列（策略 B 落地）；延迟隐藏（ADR-036）落在第 15、21 章。
> 权威来源：从 `architecture-design.md` §4.8 拆出，吸收确定性模型与双执行策略（原 §6，已并入本文件）与 ADR-006 / ADR-007 / ADR-019 / ADR-035 / ADR-036 / ADR-038。

## 1. 双执行策略（策略 A / 策略 B）

| 维度 | 策略 A（默认） | 策略 B |
|---|---|---|
| 线程 | 单线程 | N 个工作线程（与 `se_count` 独立配置） |
| 波领取 | 固定轮转（ADR-007） | CU 内原子领取 |
| 图元/像素 | 固定顺序 | SE 屏幕 tile 静态分区（ADR-019），区内固定顺序 |
| 内存 | 单一 TLB 视图 | 线程本地 TLB + 全局失效 |
| 用途 | 黄金基线、定位 | 并行行为、性能、竞争缺陷 |

规则：

1. 31 章之前 `exec_mode=parallel` 必须报"策略 B 未实现"，**不得静默退化为串行**。
2. 31 章之后，`se_count × worker_threads` 的可用组合在探针上**零容差**一致。
3. 切片数与线程数解耦：切片数由派发容量决定，线程数只决定谁执行。
4. 归约/原子顺序写死；barrier 不依赖线程到达顺序。
5. 统计（波数、像素数、命中率）是软观测；正确性只看硬判据。

## 2. 时间无关（作用域澄清，两阶段共同）

时间无关约束**作用于硬件路径与主机时钟**——硬件内部全部事件只依赖两类逻辑时间源：`frame_index`（帧序号）与 `timeline-semaphore / fence` 逻辑时间戳；`std::steady_clock` / 系统时钟**只用于性能耗时统计**，禁止参与硬件状态、着色器执行、内存判断、屏障逻辑。着色器内可以使用按 `frame_index` 确定性推导的周期参数（如旋转角），`frame_index = n` 的画面必须等于"直接以 n 初始化"；禁止 `uTime` / `clock()` / 墙钟差值进入硬件状态或 CPU 位姿复算。

## 3. 确定性（两阶段共同）

- 任何并行度、线程数、调度顺序下，硬判据必须一致；任何硬判据不一致一律先视为缺陷，而不是"并行正常波动"。
- **内存别名与重排序**：硬件单元不会自动消除内存别名、不会自动插入屏障，严格按照内存序执行读写；别名是上层应用/驱动责任；模拟器核心硬件路径不做全局别名检测（开销大），别名检测仅作为 tools 调试工具、可开关、不改变结果。
- **分配可复现**：随机行为绑定可复现伪随机种子，禁止直接调用主机全局 `rand()`（`../docs/design/memory-system.md` §7）。
- 位姿可复算：只由 `(scene_id, frame_index, camera_params, model_matrix)` 决定。
- 遍历顺序固定、归约顺序固定、平局可判、内存序显式（完整清单见 `roadmap.md` §5.5）。

## 4. 功能级流水线与背压（ADR-035）

单元间以输入 FIFO + 输出 FIFO + valid/ready 握手连接；下游忙（FIFO 满）则反压上游停发；多图元 / 多波可同时在不同阶段流动（不做周期精确）。`IEngine` 按 Push/Pump/Pop 握手定义（见 `architecture-design.md` 层间接口契约 §3.3）。软观测：每级 FIFO 平均占用率、反压周期计数。

## 5. 延迟隐藏（ADR-036）

高延迟操作（纹理采样等）异步化：波发出请求即挂起、让出 CU 给就绪波，结果返回后唤醒；波调度器维护"就绪波队列"。这是理解 SIMT 调度动机的前提，软观测：波切换次数（`roadmap.md` §0.7 硬件行为原则、§2.8）。

## 6. 硬件资源上限 / occupancy（ADR-038）

CU 驻留 wave 数、SGPR/VGPR/LDS 总容量、FIFO 深度、描述符堆容量固定且可配置；超限排队等待释放而非报错（第 31 章落地，`roadmap.md` §2.8）。

## 7. 与参数相关的配置

`exec_mode` / `worker_threads` / `se_count` / `cache_enable` 等配置键定义以 `roadmap.md` §5.1 为权威；各章与双策略的关系表见 `roadmap.md` §5.3。

## 8. 契约变更

- 并行确定性规则、三维 workgroup 映射、occupancy 上限均为冻结契约，变更走 `roadmap.md` §7.4（新建 ADR）并回归 S11/S18；并行相关场景在 `parallel` 下硬判据不得回退。
