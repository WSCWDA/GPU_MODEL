# 校验模型 — 独立模块设计

> 项目目标、范围、阶段与交付以[任务规划](../CPU模拟GPU教学项目_任务规划与实施规格.md)为主干；roadmap展开章级任务，architecture-design定义模块树与层间契约。本文负责本模块的内部技术设计。

> 定位：定义正确性判定的唯一体系：校验分层（L1 契约 / L2 解析模型 / 横切差分）、探针与基线、场景规约（scene-specs）、窗口与 headless 约束、以及 CI 诊断产物与回归矩阵。**参照源只用 CPU 参考模型（`tools/ref_model`），不做真机 / 外部 GPU 参照渲染（ADR-027）。**
> 落地章：第 7 章起全面采用；初级 E0~E5 全图逐字节；高级 S0~S19 探针表为主判据 + 全图掩码差分仅告警。
> 权威来源：从 `architecture-design.md` §4.7 拆出，吸收校验模型演进与工具链定义（§4.9 → 本文件 §7；§7 校验演进 → 本文件 §1~§6）、章节验收判据（§10.1 → `docs/design/scene-specs.md` §4）与 ADR-027。

## 1. 校验模型演进（初级 → 高级）

| 阶段 | 主判据 | 参照源 | 阻断策略 |
|---|---|---|---|
| 初级 | **全图逐字节**比对固定基线（PNG/字节数组） | 仓库内基线文件（`.raw`） | 一律阻断（不一致即失败） |
| 高级 | **固定探针点**比对（16~256 点/场景） | CPU 参考模型生成的探针期望值 | 一律阻断 |

高级阶段保留的全图逐字节只作为可选调试导出 `--dump-all`，不再作为判据（并行与浮点滤波使得全图逐字节不可维护）。

**初级不引入探针表 / `spec_runner` / `scene_snapshot`，只用全图逐字节 + 结构断言（Q-39）；探针推迟到高级。**

## 2. 校验分层与参照归属

| 级别 | 参照源 | 判据强度 | 失败处理 | 是否进门禁 |
|---|---|---|---|---|
| L1 契约/结构 | 结构体/枚举断言、汇编往返、完成计数、fence 顺序 | 零容差 | 阻断 | 是 |
| L2 解析模型 | CPU 参考模型（像素中心、覆盖率、LOD、混合公式）+ 探针表点比对 | 明确容差 | 阻断 | 是 |
| 横切 | 串行/并行、多后端（HLI/Vulkan/D3D12/GL）、开关差分 | 零容差 | 阻断 | 是 |

- **参照源只使用 CPU 参考模型**：统一放 `tools/ref_model/`，场景程序与探针表生成共用；参考模型自身用"手算解析值"单测，不得拿模拟器输出自证。**不接入宿主真机 / 外部 GPU 渲染对照**。
- **容差集中管理**：默认容差写在 `tools/ref_model/tolerances.toml`，§4 的数值是默认值，可按场景覆盖；禁止把容差散落在场景代码里。
- **每章 DoD 必须声明所属级别**；场景 spec 的判定矩阵进一步区分阻断 / 告警 / 观测 / 人工四类。

## 3. 高级探针模型

本节只适用于高级阶段；初级不引入探针表（Q-39）。

| 角色 | 产生者 | 用途 | 是否阻断 |
|---|---|---|---|
| 被测对象 | CPU 模拟器（渲染通路本身） | 输出探针点 / 全图 | — |
| 探针期望值 | `tools/ref_model`（解析计算或固定基线） | 探针表真值来源 | 是 |
| 探针表 | `tools/ref_model/probes/s<XX>_probes.txt` | 固定坐标 + 容差 | 是 |

- 探针表每场景一份，坐标用归一化 Q16（与 `rt_size` 解耦），固定顺序 `(y, x)` 升序，数量 16~256，必须覆盖前景内部、图元边缘、背景、纹理角点、被遮挡区；
- 探针表是**场景输入的一部分**，禁止运行期动态生成，改动需在章文档登记；
- 探针期望值来自模拟器自带的 CPU 参考模型（解析计算或固定基线），不在代码内硬编码、不由宿主真机渲染得到；
- 容差：颜色 ±2/通道、深度 ±1 LSB、覆盖率 ±1/16 子样本、计数/状态类为 0（不进探针表，直接用断言）；
- 探针表随渲染逻辑同步维护：任何改变像素输出的实现变更，必须在同一次提交内更新探针表，否则 CI 会持续失败。

## 4. 判定与容差细节

- L1 契约/结构 | 包格式、枚举、地址对齐、ABI 分区、状态机转移 | 零容差 | 阻断。
- L2 解析模型 | 探针点颜色/深度/覆盖率/查询值，对照 `tools/ref_model` | 明确容差（§3），集中 `tolerances.toml` | 阻断。
- 横切差分 | 串行/并行、多后端、缓存开关、SE 数 | 零容差 | 阻断。
- 初级基线：全图 raw RGBA8 + 场景元数据，两次运行逐字节一致；PNG 只作人工查看。
- 容差：颜色按每通道绝对值 + 覆盖比例双阈值；深度按 ULP；查询值零容差。

## 5. 工作流

1. 场景生成输入快照（几何、纹理、常量、配置）。
2. `ref_model` 生成期望基线（初级为全图逐字节；高级为探针集）。
3. CPU 模拟器运行，收集全图输出（高级另收探针）。
4. `image_diff` 比对，输出 `{坐标/点, 期望, 实际, 差值, 级别}`。
5. 失败项必须定位到单元与包偏移；不允许"整体重跑看是否偶发"。

## 6. 配置项（配置键全表见 `roadmap.md` §5.1）

与校验相关的运行期键：`exec_mode`、`worker_threads`、`se_count`、`cache_enable`、`rt_size`、`api_backend`、`trace`、`dump_raw_output`、`max_allowed_bad_pixels`（全图掩码差分告警阈值，仅告警）、`kft_allow`、`log_level`、`hw_counters_enable`、`mem_sanitizer`。完整定义以 `roadmap.md` §5.1 为权威，此处不复制。

## 7. 辅助工具链（`tools/`）

| 工具 | 用途 | 阶段 |
|---|---|---|
| `isa_asm` / `isa_disasm` | 汇编 / 反汇编 | 初级 |
| `ref_model` / `image_diff` | CPU 参考模型生成期望 / 全图逐字节比对（高级为探针比对） | 初级 |
| `pick_probe` | 读 raw 帧输出坐标探针信息，headless 等价窗口点击 | 高级 |
| `scene_snapshot` | 生成 / 读取场景 JSON 输入快照（输入自证 + 调试复现） | 高级 |
| `spec_runner` | 读单份 `docs/design/scene-specs.md`，自动执行 CI 回归矩阵，生成 HTML 汇总报告 | 高级 |
| `log_analyze` | 批量分析日志，统计 Error/Warn 计数、过滤重复告警 | 高级 |
| `mem_audit` | 解析内存快照 dump，检测 GPU 内存泄漏 / use-after-free | 高级 |
| `state_inspector` | 硬件状态与统计查看 | 高级 |

原则：工具不链接 `hw_sim` 内部头文件，只读取模拟器导出的 dump / trace / 快照产物，headless 可用、不依赖窗口 GUI。初级只用 `ref_model` / `image_diff` 做全图逐字节 + 结构断言，不引入 `spec_runner` / `scene_snapshot`（Q-39）。

- **compute ref_model（2026-11-20 定案，D5）**：按评审落地——为每个 WA（WA-01~WA-12）各一份 CPU 参考 kernel（**同 op 序 / 同 tiling / 同归约序**，归约 = `gtid` 升序 + 树形），放 `tools/ref_model/compute/`，作为 S18/S19 的期望值来源（与其它工具一样不链接 `hw_sim`）；容差引用 `scene-specs.md` §1.2「计算数值口径」（fp32 ≤1 ULP 可配置、归约顺序断言强制）。**排期**：第 37 章前先落 WA-01/02/05（对齐 `roadmap.md` §6.6 首验门），其余 WA 随 §6.6 首验门随章推进。

## 8. 场景规约（scene-specs）与窗口/headless

- 完整规约统一写入单份 `docs/design/scene-specs.md`（**不建 `docs/scene-specs/` 目录**，Q-38），单文件内每场景一节（`Exx` / `Sxx`，标题沿用 `Exx_xxx` / `Sxx_xxx`）；统一模板十节、判定矩阵四分类、子 case、KFT 绑定、产物入库、回归矩阵的**权威描述在 `docs/design/scene-specs.md` §1**，本文件不重复展开。
- 场景输入、探针集合、阻断判据、KFT 绑定均为冻结契约，修改必须走 `roadmap.md` §7.4 工作流；`apps/scene_*` 严格对齐 `docs/design/scene-specs.md` 对应节，不得私自修改输入参数。

### 8.1 窗口与 Headless 约束（窗口功能清单）

窗口系统属于**上层调试工具**，不属于虚拟 GPU 硬件单元；初级 1~9 不强制窗口，只导出 `.raw` / PNG；窗口作为高级 E 阶段的可选开发工具实现。三条铁律：

1. **模拟器渲染源头永远是 CPU 内存帧缓冲**：`uint8_t` BGRA 原始缓冲区，内存序与全栈统一（ADR-015）；`hw_sim` / firmware / kmd / hli **完全不知道窗口、SDL、GLFW 的存在**。
2. **窗口只做位图显示**：窗口适配层放 `umd/os`，仅把 CPU 内存块上传宿主 GPU 纹理并全屏 blit；**宿主 GPU 严禁参与任何渲染、光栅、着色计算**，只作为位图显示器；窗口渲染输出绝不作为真值来源。
3. **窗口与模拟器逻辑解耦**：`rt_size` 是模拟器硬件逻辑分辨率、不随窗口缩放改变，窗口任意缩放只是双线性 / 近邻展示；`frame_index` 完全由应用提交驱动，**禁止窗口 vsync / 操作系统时钟驱动模拟器帧逻辑**（严格遵守时间无关约束）；窗口 vsync 只控制画面多久刷新到屏幕，不改变渲染输出。

**headless（CI）约束**：自动化校验完全不依赖窗口库，CI 可在无显示器 headless 环境跑全部 E/S 回归；CMake 开关 `BUILD_WITH_WINDOW=ON/OFF`；关闭窗口依赖时，`tools/ref_model`、`tools/image_diff`、探针校验工具与批量回归脚本仍完整编译。所有校验读取 CPU 内存原始缓冲区，绝不读取窗口后端帧。

**窗口功能清单（全部是软件后处理可视化，不参与任何自动化判据）**：

- 模式 `headless` / `windowed`；保存当前帧为 `.raw`（校验用，优先）与 PNG（人眼查看）；重放当前场景。
- 鼠标探针拾取：窗口坐标 → 模拟器归一化 Q16 探针坐标，控制台打印 `(x,y) | RGBA | 深度值 | coverage 子样本掩码 | primitiveID | waveID | 所在 SE 编号`（headless 等价物 `tools/pick_probe`）。
- 多调试视图切换（对 CPU 输出缓冲区做后处理，不改动模拟器硬件输出）：原始颜色 / 深度热力图 / Coverage 伪彩 / WaveID 伪彩（观察 SE 分区与并行调度）/ Hi-Z 拒绝可视化。
- 帧 dump：一键导出离线 JSON（场景参数快照、全部生成图元列表、wave 统计、全部探针点结果、硬件统计如缓存命中率与 fence 值），可离线分析、不需要重跑模拟器。

**实现阶段**：初级（1~9）不做窗口，只保证 raw / PNG 导出与 headless E0~E5 校验；高级 A~D（10~31）先做 `tools/ref_model`/`image_diff`、探针体系、全图差分告警、CI 诊断产物，跑通 S0~S11 自动化校验；高级 E（32~36）再实现窗口可视化交互工具。自动化校验优先跑通、窗口可视化放后。
