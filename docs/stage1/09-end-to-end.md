# 第 9 章 端到端验收

> 本章把第 1~8 章组装成一帧可提交的完整画面（渐变三角 + 贴图四边形 + 简单模型三条独立 draw 共用同一帧），并把初级阶段的**阶段门禁**收敛成可自动跑批的验收：E0~E5 全绿、两次运行逐字节一致、每条简化可定位、每章一份 `--trace` 样例。
> 与本章相关的设计说明：`../roadmap.md` §3.5（初级爬升纪律）、§2.3（阶段门禁三列）；`../design/validation-model.md` §1~§2（初级基线）；第 6~8 章（固定管线 / 纹理 / 帧输出）。
> 落地模块：`apps/scene_e5_end_to_end`、`hw_sim/submit/facade`（多 draw 批提交）。

---

## 1. 目标与非目标

### 1.1 目标

1. 一帧内三条独立 `DRAW` 共用同一 RT/深度：渐变三角（E2 输入）、贴图四边形（E3 输入）、简单模型切片（E4 输入子集），帧序确定。
2. 每个 draw 独立 PSO/顶点/纹理绑定，状态切换不会污染其他 draw。
3. 跑批验收：CI 脚本一条命令跑通 E0~E5，输出逐章断言汇总（全图逐字节 + 结构断言）+ 全场景 raw 基线 + 每章 `--trace` 样例收集。
4. 初级门禁三条机器判定：E0~E5 全绿且两次运行逐字节一致；每条简化假设能审计到唯一代码落点；9 份 `--trace` 样例齐备可读。
5. 支持 headless 完整跑批；窗口为可选人工检视。

### 1.2 非目标

- 不做多 draw 级并行/调度（第 15、31 章）；三条 draw 串行顺序执行。
- 不做真实场景切换缓冲（第 32 章）；不做参考模型探针的完整双轨（高级引入 L2 探针，第 10 章起）；初级不引入探针表 / `spec_runner` / `scene_snapshot`（Q-39）。
- 不新增任何硬件单元；本章是把已有单元编排成"验收对象"，不扩大简化面。
- 不做性能统计与耗时断言。

## 3. 输入输出契约

### 3.1 E5 场景输入（冻结）

| 组成 | 来源 | 说明 |
|---|---|---|
| draw1 渐变三角 | E2 输入 | `RenderVertex` 3 顶点（stride 32，红/绿/蓝） |
| draw2 贴图四边形 | E3 输入 | 2×2 纹素 + UV 全图映射 |
| draw3 简单模型 | E4 输入（完整复用） | 约 1 千三角形非索引顶点流，单条 draw（与 E4 同源，D9.1/D9.2 逐字节校验） |
| RT/深度 | 256×256 | 三条 draw 共享 |
| 背景 | `0xFF3F3F3F` | 首条 draw 前 `CLEAR` 一次 |

约束：

- draw 顺序固定（1→2→3）；每个 draw 前重发 `SHADER_PSO` 覆盖同一 PSO 工作副本（第 6 章机制，不建 PSO 对象池、不新增 stateId），顶点/纹理绑定按 draw 粒度快照，不做渐变混合。
- 三条 draw 与"单独跑 E2/E3/E4"时的**单 draw 像素集合**逐字一致（在共享帧内不互相覆盖的证明：分层帧中各区域与单场景输出一致）。

### 3.2 跑批与门禁（初级：CI 脚本直调场景）

Q-39：初级不引入 `spec_runner` / `scene_snapshot` / 探针表；跑批由 CI 脚本直接调用各场景可执行文件，"全图逐字节 + 结构断言"即每场景的全部判据。典型汇总：

```
PER-SCENE  e0  PASS 断言 N 条（全图逐字节 + 结构断言）
PER-SCENE  e1  PASS 断言 N 条（全图逐字节 + 结构断言）
...
GATE       E0~E5 全绿 + 两次运行全图逐字节一致       PASS
GATE       简化可定位审计（每 §9 简化项有落点）    PASS
GATE       每章一份 --trace 样例（9/9）           PASS
```

- 两次运行一致性：每个场景二进制连续执行两次，raw 全图逐字节比对（不引入 `--repeat` 工具参数）。
- `--trace` 样例由各场景自身的 `--trace` 输出重定向收集，仅作教学样例，不进入判据。

### 3.3 简化可定位审计

`*/§9 简化登记` 每行须映射到至少一个可 Grep 的代码符号（如 `FlatMemory`, `SingleWave`, `NoBlendFallback`）；门禁脚本用符号清单校验"无落点的简化"为 0。落点统一以 `// SIMPLIFY-<章>-<项>` 编号标注，同一简化多落点取权威一个 + 引用链（Q-83）。

## 4. 内部数据流

```
初始化：设备/环/内存 → 上传顶点+纹素（bump）→ 逐 draw 重发 PSO 覆盖暂存区
帧循环（frame_index = n）：
  CLEAR(back, 0xFF3F3F3F)
  draw1: SHADER_PSO(PSO1) → 顶点 → 渐变三角
  draw2: SHADER_PSO(PSO2) → 顶点 + texId=0 → 贴图四边形
  draw3: SHADER_PSO(PSO3) → 模型顶点 → 模型切片（完整 E4）
  FENCE → Flip → frame_index++
跑批：连续两次运行，输出断言汇总 + raw + trace 样例
```

## 8. 横向关注点

| 关注点 | 本章回答 |
|---|---|
| 确定性 | draw 顺序、绑定顺序、帧序全部显式；无随机 |
| 时间无关 | `frame_index` 驱动，无墙钟 |
| 可观测 | CI 跑批汇总、每章 trace 样例、raw 基线 |
