# 第 16 章 ISA + 汇编器

> 本章把 ISA 从"内存内指令结构 + 解释器"升级为完整 64 bit 定长编码 + 汇编器/反汇编器，并冻结 Shader ABI 分区。本章只做编码 / 汇编 / 反汇编 / 解码；曲面/几何语义归第 28 章，subgroup 语义归第 29 章，ALU/控制流/内存/内建等语义由第 4、5、15 章及对应硬件章节承担。这是编译器（17~19）与执行（4/15）的共同底座，所有消费方只连 `common/isa.h`。本章验收核心：汇编 → 二进制 → 反汇编 → 再汇编二进制完全相同；全指令集 smoke 无解码失败。
> 与本章相关的设计说明：`../design/isa-abi.md` §1~§4（64 bit 编码、opcode 区段、ABI 分区、汇编器验收）；ADR-018/033/034；`../design/command-mmio.md`（无冲突，CP 只经包）。
> 落地模块：在第 5 章的 `hw_sim/isa` 上扩展共用解码/指令入口，汇编和反汇编沿用公共编码契约，`hw_sim/shader/wave` 持有执行状态。

## 1. 目标与非目标

### 1.1 目标

1. 64 bit 定长编码完整落地：`[63]=SFLAG / [62:56] opcode（7 bit）/ [55:48] dstReg / [47:40] src0 / [39:32] src1 / [31:0] imm32`；opcode 区段按 `../design/isa-abi.md` §2 已落 7 bit 表（原 `0x80~0xFF` 内容重排：曲面/几何 `0x60~0x6F`、subgroup `0x70~0x7D`、`0x7E=UNDEFINED`、`0x7F=EXIT`，ADR-043）。
2. opcode 编码按 `../design/isa-abi.md` §2 唯一表实现；对每个已分配 opcode 验证 encode/decode 往返，对保留码验证确定拒绝。语义所有权按本章顶部的章节责任划分，不复制执行语义。
3. 汇编器：文本 → 二进制；反汇编器：二进制 → 文本；往返一致（汇编→反汇编→汇编二进制逐字节相同）。
4. 全指令集 smoke：编码/反汇编覆盖全 opcode，无解码失败（`UNDEFINED` 仅用于未知编码）。
5. 标量/向量分区：编码位区分；SGPR/VGPR 独立编号空间（`s0..s31` / `v0..v127`）；ABI 固定分区（输入 `v[0..15]`、VS out `v[16..27]`、HS 因子 `v[28..35]`、PS out `v[36..39]`(RT0)/`v[40..43]`(深度)/`v[44..55]`(RT1~3)、uniform `v[56..67]`、距离 `v[68..75]`、临时 `v[76..]`，`../design/isa-abi.md` §3 权威）。
6. 计算指令与特殊寄存器（`GET_THREAD_ID` 等）可汇编/反汇编。

### 1.2 非目标

- 不做"优化器"；汇编器只做汇编与格式校验（编译优化在第 18 章）。
- 不做重定位/链接；指令相对偏移直接编码（无符号表重定位需求，stage3 38~42（原 35.5）的 module 亦如此）。
- 不改动初级已有指令语义；初级最小 ISA 升级为完整集，不破坏 E 场景。
- 不做反汇编的寄存器别名语义提升（按 ABI 分区原样输出寄存器号）。

## 2. 单元框图

```
     工具            运行时
 文本 → 汇编器 → bin → 解释器(第 4/15 章)  ← 编译器输出(17~19)经同一 bin
       bin → 反汇编器 → 文本 → (可选再汇编) → bin（逐字节一致）
       common/isa.h（编码唯一权威）
```

- `isa_asm` 读 `.s`（文本）产 `.bin`；`isa_disasm` 读 `.bin` 产 `.s`。
- 解释器按 `common/isa.h` 解码（执行语义由 opcode 所属硬件单元章节负责：基础 ALU/控制流见第 4/5/15 章，Tess/GS 见第 28 章，subgroup 见第 29 章，LDS/原子/barrier 见第 30 章）；编码错误 → `InvalidIsa`（可定位）。

## 3. 输入输出契约

### 3.1 编码（`common/isa.h`）

```cpp
struct Insn {
    u8  opcode;   // [63]=SFLAG（最高位）、[62:56]=opcode（7 bit）
    u8  dstReg;   // [55:48]（SGPR/VGPR 由 opcode 区段语义决定）
    u8  src0;     // [47:40]
    u8  src1;     // [39:32]
    i32 imm;      // [31:0]
};
// encode(Insn)->u64 / decode(u64)->Insn 对称；分支 imm 有符号相对 pc
```

- `MOV src0==0xFF` 哨兵 = 写立即数。
- `dstReg` 是"统一编号"字段；实际空间由 opcode 的标量/向量位区分（ADR-034）。
- opcode 仅 7 bit（`[62:56]`），`[63]=SFLAG` 区分标量/向量；区段按 `../design/isa-abi.md` §2 已落 7 bit 表（曲面/几何 `0x60~0x6F`、subgroup `0x70~0x7D`、`0x7E=UNDEFINED`、`0x7F=EXIT`，ADR-043）。

### 3.2 文本语法（汇编器输入）

```
label:          // 3~32 字符 [A-Za-z_][A-Za-z0-9_]*
   ADD  v0, v1, v2
   LD   v3, [s2+offset]      // 内存
   BRC  label, p0            // 条件分支
   GET_THREAD_ID s5          // 内建
   EXIT
```

- 操作数：`s<0..31>` / `v<0..127>` / 立即数(十进制或 `0x` 十六进制) / 标号(divmod→相对偏移)。
- 汇编器做静态校验：未知指令、非法寄存器号、类型不匹配 → 对行号报错。

### 3.3 ABI 分区（`../design/isa-abi.md` §3 冻结）

| 关键区 | 编号 | 用途 |
|---|---|---|
| 输入属性 | `v[0..15]` | IA 装配 |
| VS 输出 | `v[16..27]` | 阶段间 |
| HS 因子 | `v[28..35]` | 曲面细分因子备位 |
| PS 输出 | `v[36..39]`(RT0) / `v[40..43]`(深度) / `v[44..55]`(RT1~3) | OM 写回 |
| uniform | `v[56..67]` | 小高频常量（kernel 参数区起点 `v[56]`） |
| 距离 | `v[68..75]` | Clip/Cull（ADR-033） |
| 临时 | `v[76..]` | 线性扫描起 |
| SGPR | `s0..s31` | 波内一致值 |

分区不允许被临时量覆盖；`SymbolBindings` 只是机器编排。分区数值以 `../design/isa-abi.md` §3 为唯一定义处。

## 4. 内部数据流

### 4.1 汇编流水

```
text → 行 → token(正则) → label 表(收集两遍)
→ 指令行 → 操作数类型推断 → encode → bin(+可选对齐)
→ 校验：label 引用在文本内；imm 值域 [s32]
```

- 两遍：第一遍收集标号地址，第二遍解析相对偏移（`target - pc - 1`）。

### 4.2 反汇编流水

```
bin → 每 u64 → decode → 文本 → 对齐缩进（不重算地址）
往返断言：asm(bin) 一次 → disasm → asm 与原始 bin 逐字节相同
```

## 7. 场景与判据（A16）

**绑定场景：S0 `scene_s0_selftest`（指令自检）。本章只做编码/汇编/反汇编/解码，ALU/控制流/内存语义由第 4/5/15 章负责，Tess/GS 由第 28 章负责，subgroup 由第 29 章负责，LDS/原子/barrier 由第 30 章负责；S3 消费编译器产物属第 17~19 章验收，不并入本章。**

| 项 | 内容 |
|---|---|
| 输入 | S0：全 opcode 汇编样例 + 反例集 |
| 产物 | 汇编往返对比结果、反汇编文本、解码 smoke 通过证明 |
| 主判据 | S0：往返逐字节一致 + 全指令 smoke 无解码失败 |
| 本章专有判据 | ① 汇编往返二进制相同；② 全指令集 smoke 无解码失败（无 `UNDEFINED` 误报） |
| 回归项 | R16：E0~E5（初级手写 ISA 编码不变）不退化；未列明历史 A 门禁不自动阻断 |
| 后续补齐 | 编译器 17~19 的产物经本编码消费；符号表/重定位需求在本章明确无（stage3 38~42（原 35.5）module 用 `codeBaseVa+entryOffset`） |

## 8. 横向关注点

| 关注点 | 本章回答 |
|---|---|
| 确定性 | 标号两遍解析顺序固定；编码确定性（同一文本 → 相同 bin） |
| 时间无关 | 无需时间输入 |
| 可观测 | 往返 diff、smoke 通过率、`--trace=isa` 解码单行 |
| 契约影响 | 编码布局、opcode 区段、ABI 分区冻结；编译器只连 `common/isa.h` |
| 简化登记 | 初级最小 ISA（线性内存结构）→ 完整 64 bit 编码 + 汇编器 |
| 计算兼容 | subgroup/内建区段为计算预留；计算 kernel 走同一编码（37/stage3 38~42，原 35.5） |
| 配置与回退 | 无开关；`warp_size=32` 固定 |
| 调试钩子 | `--trace=isa`：每次取指一行 `{pc, word, mnemonic, mask}` |
| trace 契约 | 不进入判据 |
| 契约变更 | 编码/opcode/ABI 为冻结契约；变更走 ADR 回归 E0~E5 与受影响 S |
| 校验归属 | L1（结构/往返/解码 smoke） |
| 双策略 | 解码/汇编与执行策略无关；两策略下同一 bin 输出一致 |
| 阶段衔接 | B 阶段门禁 2（ISA 编码与 Shader ABI 冻结）在此章达成；编译器 17 在此之后启动 |
